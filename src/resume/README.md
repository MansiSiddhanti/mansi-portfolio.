# Resume

Drop a **single PDF** in this folder and the portfolio will use it automatically.

## How to update your resume

1. Delete the existing PDF in this folder.
2. Add your new resume PDF here (any filename ending in `.pdf`).
3. Save / redeploy.

The "Resume" buttons across the site update automatically — no code changes required.

> Note: keep only one PDF in this folder. If multiple exist, the first one is used.
