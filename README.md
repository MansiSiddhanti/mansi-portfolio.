# Mansi Siddhanti — Portfolio

React + TypeScript + Vite + Tailwind portfolio (same codebase as `../anurag-portfolio`).

```bash
npm run dev      # local dev server
npm run build    # production build into dist/
```

- All content lives in `src/data/portfolio.ts` (profile, experience, skills, projects, education, certifications).
- Project architecture diagrams (Mermaid) live in `src/data/projectArchitecture.ts`, keyed by project id.
- Résumé: drop a single PDF into `src/resume/` (see `src/resume/README.md`).
